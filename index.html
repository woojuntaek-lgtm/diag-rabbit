🔄 역행렬이 필요 없는 직교 대각화: A = Q Λ Qᵀ

길이를 1로 맞춘 직각 고유벡터를 기둥으로 세운 Q는 Q⁻¹ = Qᵀ — 무거운 역행렬 계산이 자리 바꾸기로 끝납니다. 공분산 행렬을 이렇게 나누면 Q의 기둥이 주성분 방향, Λ가 그 방향의 분산입니다.

🐍 파이썬으로 확인하기

import numpy as np A = np.array([[4, 1], [2, 3]]) w, P = np.linalg.eig(A) # w = [5, 2], P의 기둥 = 고유벡터 A10 = P @ np.diag(w**10) @ np.linalg.inv(P) # 6510758 … S = np.array([[2, 1], [1, 2]]) lam, Q = np.linalg.eigh(S) # 대칭: 실수 고유값 [1, 3], 직교 Q np.allclose(Q @ np.diag(lam) @ Q.T, S) # True — 역행렬 대신 전치 phi = (1 + 5**.5) / 2 round(phi**100 / 5**.5) # 354224848179263111168 ← 뒷자리 틀림! # 정수 행렬 거듭제곱이나 decimal(정밀도 60)이면 21자리 정확

📌 세 줄 정리

  1. 대각 행렬의 거듭제곱은 대각선 숫자만 거듭제곱하면 된다.
  2. 독립인 고유벡터가 n개면 A = P D P⁻¹로 대각화되고, Aⁿ은 D만 n제곱하면 된다.
  3. 대칭 행렬은 실수 고유값과 직각 고유벡터를 가져 Q Λ Qᵀ로 깔끔하게 나뉜다.
