# 토끼 행렬 계산소

21자리 피보나치 수가 1.618 하나로? — 행렬의 대각화를 손으로 체험하는 앱입니다. 차례로 더한 F₁₀₀과 φⁿ/√5 공식(보통 실수 vs 정밀도 60자리)의 비교, 대각 행렬의 거듭제곱, 원이 P⁻¹·D·P를 거쳐 타원이 되는 닮음 변환, 대각화 네 단계와 결함 행렬, Aⁿ = P Dⁿ P⁻¹ 지름길(A¹⁰ 정확 일치), 황금비로 다가가는 이웃 비율과 피보나치 행렬의 고유값 φ·ψ, 구독 마르코프 체인의 평형 2/3, 대칭 행렬의 직각 고유벡터와 Q Λ Qᵀ 직교 대각화까지 담았습니다. 선형대수 09 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 대각 행렬: F₁₀₀ 세 가지 계산 비교, 대각 행렬 거듭제곱과 곱셈 수
- ② 대각화: P⁻¹·D·P 단계 그림, 대각화 네 단계, 퀴즈 ①(결함 행렬)
- ③ 거듭제곱: P Dⁿ P⁻¹ 지름길, 퀴즈 ②(1.618)와 비율 그래프, 황금비 고유값, 마르코프 체인
- ④ 대칭: 대칭 vs 비대칭 고유벡터 각도, Q Λ Qᵀ 단계, numpy 코드, 세 줄 정리, 생각해 볼 질문
